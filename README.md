# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
 step 1:Select Sketch and Create Sketch and pick the Front plane. Use the origin as the centre. Place a point 50 mm right and 60 mm up for the top-right circle, and a point 70 mm to the right on the horizontal axis for the side circle.

 step 3:Draw a horizontal and vertical Centre Line using the Line Tool.
